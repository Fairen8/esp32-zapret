# Security Policy / Политика безопасности

## Reporting / Как сообщить

Приватно — через GitHub Security Advisories: вкладка **Security** →
**Report a vulnerability**.

Privately — via GitHub Security Advisories: **Security** tab →
**Report a vulnerability**.

## Scope / Область

- Проект — инструмент обхода DPI для личного использования, распространяется
  «как есть» под лицензией MIT, без гарантий (см. [LICENSE](LICENSE)).
- Не прикладывайте к issue реальные токены ботов, пароли Wi-Fi и MAC-адреса.
- Вопросы про блокировки (ТСПУ/DPI), сборку и настройку — это обычные issue,
  не security-отчёты.
