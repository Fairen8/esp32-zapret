# Contributing

Спасибо за интерес к проекту!

## Баги и идеи

Открывайте issue. Для багов приложите, пожалуйста:

- модель платы и версию ESP-IDF (`idf.py --version`);
- лог из `idf.py monitor` (особенно строки `desync` и `telegram`);
- вывод `/status` из бота;
- провайдера/регион, если проблема касается обхода DPI.

## Pull requests

- Ветка от `main`, один логичный набор изменений на PR.
- Стиль кода — как в существующих файлах ESP-IDF-компонента (C17, без лишних
  комментариев, статические функции для внутренней логики).
- Сборка должна проходить: `idf.py build` под ESP-IDF v5.3.x, цель `esp32`
  (это же проверяет CI).
- Никогда не добавляйте реальные токены, пароли и MAC в репозиторий — только
  `main/secrets_example.h`.
- Новые публичные функции компонента `esp_desync` — с объявлением в
  `components/esp_desync/include/esp_desync.h`.

## Тестирование

- Минимум: успешная сборка.
- Полезно: проверка на реальном устройстве с описанием провайдера, режима
  `/desync` и TTL, при которых обход работает (или не работает).
